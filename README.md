# Python overview

An overview of Lists, tuples, sets and dictionaries in Python.

## Tech stack

- Python 3

## Contents

- `dict_simple.py`: functions `find_student`, `mark_average_by_group`, `get_major_student`
- `functions_exercises.py`: functions `Max`

## How to run

Requirements: Python 3.

python insurance_reclams.py
